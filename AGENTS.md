# AGENTS.md

This document provides an overview of the project structure for developers and AI agents working on this codebase.

## Project Overview

AI Doctor is a symptom-checker chat app. Users describe symptoms and receive AI-generated guidance on possible
causes, self-care, and when to seek professional or emergency care. Conversations persist per browser (via a
session id in `localStorage`) using Netlify Database.

### Tech Stack

| Layer | Technology |
|-------|------------|
| Framework | TanStack Start |
| Frontend | React 19, TanStack Router v1 |
| Build | Vite 7 |
| Styling | Tailwind CSS 4 |
| AI | TanStack AI, streamed over SSE, via Netlify AI Gateway |
| Database | Netlify Database (Postgres) + Drizzle ORM |
| Language | TypeScript 5.9 |
| Deployment | Netlify |

## Directory Structure

```
├── db
│   ├── schema.ts  # Drizzle schema: chat_sessions, chat_messages tables.
│   └── index.ts    # Drizzle client (drizzle-orm/netlify-db), no manual connection string needed.
├── netlify/database/migrations  # SQL migrations generated by drizzle-kit; applied automatically by Netlify at deploy time.
├── src
│   ├── lib
│   │   ├── ai-hook.ts  # useAIChat hook: wraps useChat with SSE connection to /api/chat, optional sessionId and initialMessages.
│   │   └── chat-history.functions.ts  # createServerFn to load a session's saved messages from the database.
│   ├── routes
│   │   ├── __root.tsx  # Root layout: HTML shell, styles, TanStack Devtools.
│   │   ├── api.chat.ts  # POST handler for /api/chat: multi-provider AI (Anthropic/OpenAI/Gemini/Ollama) with SSE streaming; persists each user + assistant message to the database.
│   │   └── index.tsx  # Home route: AI Doctor chat UI, loads prior history for the session, "New conversation" button, medical disclaimer copy.
│   ├── router.tsx  # TanStack Router setup.
│   └── styles.css  # Tailwind + prose/markdown styles for chat UI.
├── drizzle.config.ts  # Drizzle Kit config; migrations output to netlify/database/migrations.
├── netlify.toml  # Netlify deployment config.
└── vite.config.ts  # Vite config: TanStack Start, React, Tailwind, Netlify plugin.
```

## Key Concepts

### File-Based Routing (TanStack Router)

- `__root.tsx` - Root layout wrapping all pages
- `index.tsx` - Route for `/`
- `api.chat.ts` - Server API endpoint for `/api/chat`

### Chat history persistence

Each browser gets a random session id stored in `localStorage` (`ai-doctor-session-id`). It's sent as `sessionId` in
the chat request body. `api.chat.ts` writes the user's message before calling the model, and streams the assistant's
response through a small async-generator wrapper (`trackingStream`) that accumulates the full text and writes it to
the database once the stream ends — this keeps persistence from blocking the live SSE stream. On page load,
`chat-history.functions.ts#getSessionMessages` fetches saved messages for that session so the conversation survives
reloads. "New conversation" simply generates a fresh session id and clears local state.

### AI Integration

Multi-provider AI chat with fallback chain (first available API key wins):

1. Anthropic Claude (`claude-haiku-4-5`)
2. OpenAI (`gpt-4o`)
3. Google Gemini (`gemini-2.5-flash`)
4. Ollama (local, `mistral:7b`)

In production on Netlify, provider credentials are injected automatically by AI Gateway — no manual API keys needed.
See the `netlify-ai-gateway` skill for the supported model list before changing models.

## Database

Schema lives in `db/schema.ts`. Any schema change requires a new migration:

```bash
npx drizzle-kit generate --name <descriptive_name>
```

Never hand-edit files in `netlify/database/migrations/` once applied — Netlify applies migrations automatically at
deploy time; do not run `drizzle-kit migrate` or `push`.

## Conventions

### TypeScript
- Import paths use the `@/` alias for `src/*`
- Zod for schema validation (server function inputs, tool schemas)

### Styling
- Tailwind CSS utility classes, no separate component library

## Development Commands

```bash
pnpm dev      # Start dev server (vite dev --port 3000)
pnpm build    # Production build
```

Use `netlify dev --port 8889` instead of `pnpm dev` when you need local emulation of Netlify Database / AI Gateway.
